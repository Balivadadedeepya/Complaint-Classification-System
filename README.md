# 📢 Complaint Classification System

A machine learning project that classifies customer complaints into relevant categories using Natural Language Processing (NLP).

## 🎯 Project Overview

This project demonstrates how machine learning and NLP techniques can be used to automatically classify text-based complaints.

The system takes a complaint as input and predicts its relevant category.

## 🔄 How It Works

1. 📝 User enters a customer complaint.
2. 🔤 The complaint is converted into numerical features using TF-IDF.
3. 🤖 A Logistic Regression model analyzes the text.
4. 🏷️ The system predicts the complaint category.
5. 📊 A confidence score is displayed to the user.

## 🧪 Example

**Input:**
> My WiFi keeps disconnecting.

**Predicted Category:**
> Internet Issue

The application provides the predicted category along with the model confidence.
